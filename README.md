# Орбита — корпоративный портал

Статическая вёрстка корпоративного портала для сотрудников вымышленной компании
ООО «Орбита»: новости, сотрудники и оргструктура, отпуска, заявки, база знаний
и раздел администрирования.

Проект выполнен в рамках дисциплины «Фронтенд и бэкенд разработка».

**Демо:** https://fluffy0602.github.io/kr3-html-portal/

## Запуск

Сборка не нужна — это обычные HTML, CSS и JavaScript без зависимостей.

- открыть `index.html` двойным кликом (работает и через `file://`);
- или поднять локальный сервер в корне проекта:

  ```sh
  python3 -m http.server 8000
  ```

  и открыть http://localhost:8000.

Все данные демонстрационные. Изменения, сделанные на страницах портала и в
админке, сохраняются в `localStorage` браузера (ключ `orbita-db-v1`); чтобы
вернуть исходные данные, достаточно очистить данные сайта в браузере.

## Структура проекта

### Портал

- `login.html` — страница входа;
- `index.html` — дашборд: дни рождения, отпуска, замещения, счётчики;
- `news.html`, `news-article.html` — лента новостей и статья;
- `surveys.html` — опросы;
- `employees.html` — справочник сотрудников;
- `birthdays.html` — дни рождения;
- `org.html` — оргструктура;
- `vacations.html`, `on-vacation.html` — отпуска и кто сейчас в отпуске;
- `substitutions.html` — замещения;
- `requests.html` — заявки;
- `vpn.html` — доступ к VPN;
- `knowledge.html` — база знаний;
- `services.html` — корпоративные сервисы;
- `profile.html` — профиль сотрудника;
- `404.html` — страница «не найдено».

### Администрирование (`admin/`)

Сотрудники, роли и разрешения, оргструктура, должности, города, новости и их
категории, опросы, отпуска (очередь, календарь, настройки), типы и категории
заявок, база знаний (материалы, разделы, типы), сроковые письма, замещения,
сервисы, VPN и журнал аудита.

### Ресурсы

- `css/style.css` — базовые стили, каркас страниц, компоненты;
- `css/app.css` — интерактивные части: модальные окна, формы, админка;
- `js/data.js` — демо-данные и их сохранение в `localStorage`;
- `js/ui.js` — общие помощники и оболочка: сайдбар, шапка, подвал;
- `js/portal.js` — логика страниц портала;
- `js/admin.js` — логика страниц администрирования;
- `images/logo.svg` — знак логотипа, `images/favicon.svg` и
  `images/apple-touch-icon.png` — иконки сайта;
- `fonts/` — шрифт Golos Text (SIL Open Font License 1.1).

## Используемые технологии

- HTML;
- CSS (Flexbox, Grid, медиазапросы, адаптивная вёрстка);
- JavaScript без фреймворков и сборки;
- Git, GitHub, GitHub Pages.
